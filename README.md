# Summary

UD_Bonan-GDUD is a treebank of Bonan (Bao'an), a Mongolic language spoken in Gansu and Qinghai provinces of China. The treebank consists of grammatical example sentences converted from a reference grammar and manually curated to conform to Universal Dependencies guidelines.

# Introduction

The Bonan treebank contains 1152 sentences of Bonan (ISO 639-3: peh), one of the Mongolic languages of the Gansu-Qinghai Sprachbund. The data consist of grammatical example sentences extracted from reference grammars of Bonan, presented in IPA/Latin transliteration and accompanied by English translations.

All sentences are annotated with lemmas, universal part-of-speech tags (UPOS), morphological features, and dependency relations. The annotation prioritizes UD core morphological features and dependency relations, while introducing a small number of language-specific features and relations to capture distinctions that are morphologically or syntactically overt in Bonan.

Because the entire treebank consists of grammatical examples of limited size (fewer than 20K words), all data are provided as a test file for cross-validation, following UD guidelines for small treebanks.
